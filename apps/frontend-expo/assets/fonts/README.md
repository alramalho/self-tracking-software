Inter is the sans-serif family used by the original Vite frontend. These static
400, 500, 600 and 700 faces come from Expo's Google Fonts distribution:
https://github.com/expo/google-fonts/tree/main/font-packages/inter

The fonts are bundled locally for offline native startup. See OFL.txt for their
SIL Open Font License. Application text uses explicit faces so Android and iOS
render medium and semibold weights consistently; system navigation stays native.

Caveat is the PWA's cursive family, used for profile badge counts. The variable
font is bundled for offline startup from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/caveat
See Caveat-OFL.txt for its SIL Open Font License.
